# 大错与有限修复

## 修复范围

| 确定的大错，可以局部修复一次 | 普通问题，不自动修改 |
|---|---|
| 九宫格缺失、标题错误、字幕大面积遮挡 | 标题可以更漂亮、轻微排版偏好 |
| 画风变成真人、主角明显换人、清晰多肢体、剧情画反 | 轻微色差、背景简单、普通遮挡或透视疑点 |
| 配音漏句、大量重复、明显卡顿/持续杂音压住人声 | 自然停顿、轻微语气差异、仅ASR低置信 |
| 字幕切图明显错句、黑屏、截断、没有声音 | 与ASR估计相差极小的时间值 |

没有确定依据时先保持原件；只对关键疑似大错放大看图或听对应区间。不能把“感觉还能更好”写成失败。

## 一轮局部修复

记录具体位置、原件和可见修改目标。每个质量问题最多一轮局部修复，只核对修改位置及必要相邻部分；没有明确改善就停止该处，不继续试整片或改动无关内容。仍有明确大错时保留产物并说明，不能称最终完成。

图片在 image_repair_directives.json 只为问题镜头填写 issues、required_changes、preserve、avoid、repair_round=1。原平台生成器的 --repair-ids 只处理这些镜头；新图实际确认有改善才安装为当前图。local_repair.py 保留一个回退图；新图仍差时回退，停止自动质量返工。

空文件或图片下载失败按平台流程有限恢复。用户提供的音频有明确内容问题时，请其提供修订文件。音频输入检查见 [audio-input.md](audio-input.md)。

## 维护与生产分开

Skill 改动后，在隔离小样中验证实际行为、失败案例和回退。日常制作不运行单元测试、不做模型能力评测，也不让执行者为了通过检查临时改工具代码。检查失败先判断是否真正大错，再按本页处理。
