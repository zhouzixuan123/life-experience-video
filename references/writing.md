## 1. 已验证风格

让观众以第二人称进入一个具体身份，用连续选择体验该身份的奖励、升级和最终去向。

保持真实、克制、具体和有命运感。允许结局沉重，但不要为了刺激而猎奇或强行卖惨。人物获得的成功、快乐或利益必须真实存在，代价也必须真实存在。

可按选题使用的叙事方法：

- 使用第二人称“你”形成沉浸感。
- 用精确时间、生活物件、身体动作和经济细节落地场景。
- 建立一句能驱动人物继续选择的“危险等式”。
- 通过称呼、关系、房间、账单等变化表现时间和身份升级。
- 选择一个核心物件贯穿全文，并在结尾改变其含义。
- 先用最后一个具体画面完成回扣，再用至多一句判断收束主题。
- 不把人物简单写成坏人、蠢人或受害者，要让错误选择在当时具有合理诱因。

参考他人作品时只分析通用结构，不复用其独特表达、角色设定或具体情节。用户只给题目且没有规定时长或字数时，正文默认目标为约 2500 个非空白中文字符，验收区间为 2400—2600 字；不计标题、状态说明、标点和空白行。完整人生跨度也应优先压缩场景、合并重复信息，不得自行突破上限。只有用户明确指定时长或字数时，才按处理后配音目标调整篇幅，并保持每段都有推进作用。

## 2. 核心叙事公式

> 身份承诺 → 原始缺口 → 第一次奖励 → 自我合理化 → 逐级升级 → 代价显形 → 不可逆清算或冷峻定格 → 首尾回扣

固定开头旁白采用“主题爆点冷开场 → 品牌引导语 → 主题 → 正文”的顺序。每期默认先写四个冷开场配音节拍，两行组成第一句、两行组成第二句：

```text
[节拍1：选择或前提]
[节拍2：明确决定]
[节拍3：时间或处境反差]
[节拍4：最终代价或结论]

今天你要体验的人生副本是
[本期主题]

[正文第一句]
```

冷开场四行用于前置两图爆点段；品牌引导语和主题用于后续固定片头；正文第一句再进入正文。节拍行是呼吸和字幕出现点，不等于四句互不相干的话。节拍1—2应自然连成第一句并由第1张图承载，节拍3—4自然连成第二句并由第2张图承载；句间留自然停顿，不要逐行念成播报腔。主题显示时可以拆成视觉重量接近的两行，但配音仍按完整主题自然朗读。

### 主题爆点冷开场

每期都在品牌引导语前写约 6—8 秒的主题爆点冷开场。它不局限于身份反转，也可以是极端处境、核心秘密、巨大代价、反常选择、命运结果或直接点题的中心判断。观众在冷开场结束前就应当能复述本期核心卖点，而不是只知道“后面有秘密”。

```text
[节拍1：给出最强选择、身份前提或欲望]
[节拍2：把选择说死，形成第一句]
[节拍3：切到时间、处境或关系反差]
[节拍4：落下最具体的代价、结果或中心判断]

今天你要体验的人生副本是
[本期主题]

[正文第一句]
```

冷开场优先从整篇文稿中提取最强主题点，不按正文时间顺序慢慢铺垫。第一句必须具体到身份、关系、选择、代价或结果，不能只说“你绝对想不到”“接下来的人生很离谱”等空悬念。第二句必须引入新的时间、场景、关系或后果，不得只是把第一句换一种说法。反转只是其中一种手段，不是硬要求。

四个节拍必须天然支持两张画面：第1张表现节拍1—2组成的第一句话，第2张同时容纳节拍3的处境反差与节拍4的代价定格。第二句话的两个节拍要能由同一场景递进表达，禁止写成必须依赖两个互不相干地点才能成立，也禁止写成只能由一张抽象概念图承载的判断。钩子结束后再进入“今天你要体验的人生副本是”和正式主题，不把品牌引导语塞进爆点句中。

交付前检查三件事：去掉正式标题后，冷开场本身是否仍然足够吸引；陌生观众是否能在约 6—8 秒内准确说出本期主题点；钩子中的炸裂信息是否确实由正文承接，而不是标题党。

### 配音稿输出

确认文稿之外，同步生成 `02_配音稿.txt`。该文件是给用户直接照读的纯文本，不得包含 Markdown 标题、序号、颜色标签、分镜说明、括号提示或“停顿”字样。格式固定为：

```text
[冷开场节拍1]
[冷开场节拍2]
[冷开场节拍3]
[冷开场节拍4]

今天你要体验的人生副本是
[本期主题]

[正文第一朗读节拍]
[正文第二朗读节拍]
……
```

空行只用于区分冷开场、品牌片头和正文三个录音区块，不代表额外长停顿。标点保留在配音稿中帮助自然断句；字幕生成时再统一去除标点。任何文稿修改都必须同步更新此文件，并逐行核对两者的实际朗读文字完全一致。

### 标题模式选择

标题是独立的信息产品，不是冷开场第一句的复制品。先判断选题类型，再写标题：

- 真实事件、社会争议、法律纠纷：使用“社会新闻型标题”。
- 虚构人生模拟、职业体验、欲望下坠、逆袭或身份体验：使用“沉浸体验型标题”。

项目配置把选择写入 `title_mode`：前者为 `social_news`，后者为 `immersive`。不能因为正文使用第二人称，就把社会新闻标题也改成第二人称。

“模式”只决定判断方向，不是固定句式。写标题前从身份、工具、动作、关系、地点、数字、冲突和结果中选择本期最有辨识度的一至三个信息；哪种组合最能让观众立刻明白“这期体验什么”并产生兴趣，就用哪种。标题可以是短身份、事实陈述、动作冲突或反转结果，不要求每次同时装入所有元素，也不要求固定使用逗号、前后两段或“最后/却/反而”等转折词。不要为了套公式把清楚的短标题改成长句。

#### 社会新闻型标题规则

国内社会新闻常用的高效结构是：

> 人物主体 + 异常工具或关键动作 + 核心事件 + 反常结果

这是优先参考结构，不是强制填满的四格模板。若“异常工具＋反常结果”已经足够吸引，可以省略普通背景；若结果尚不确定，就只写已确认的冲突或动作。标题第一眼至少应让人知道事件是什么，并出现一个最值得点击的具体信息，不要先写情绪评价或抽象主题。

标题信息优先级：

1. 先写最异常、最具画面感的事实，例如特殊工具、特殊地点、特殊关系或关键动作。
2. 再写观众最关心的冲突事件。
3. 结尾落在明确、具体、可核验的结果，优先使用判决、赔偿、失联、被拘、获救等结果。
4. 数字、金额、刑期可以增强新闻感，但必须有可靠来源，不得误导。

事实与法律状态必须准确：区分报案、立案、被拘、起诉、一审判决、生效判决和实际服刑。尚未实际执行的刑罚不得写成“已经坐牢”；只有一审结果时，标题写“一审被判”或“获刑”，不能暗示判决已经终局。正文资料不足以确认数字或结果时，降低精度或先核实，不得自行补齐。

禁止写法：

- 不用第二人称代入式标题，例如“最后被判刑的人却是你”。
- 不用抽象情绪代替事件，例如“输掉尊严”“真相的边界”“命运的清算”。
- 不用剧情腔、感叹句、反问句或空悬念，例如“你绝对想不到”“到底谁赢了”。
- 不把尚未实际执行的刑罚写成既成事实。
- 不使用侮辱性称呼、性别攻击或未经证实的细节。

验收时把标题脱离正文单独阅读：观众应立刻知道大致体验对象或事件，并能指出至少一个鲜明卖点。人物、异常细节、冲突和结果四项越完整越好，但不得为了凑齐四项牺牲简洁、准确或自然表达。标题没说清体验内容、只剩空泛关系或套式反转时才重写；不能只调整字号或分行。

推荐示例：

- 男子用扫地机器人录下妻子出轨证据，反被判5个月
- 男子发现妻子出轨后取证，妻子赔偿50万，他却获刑5个月
- 丈夫用家中设备录下妻子裸身画面，被判5个月

不推荐示例：

- 你抓到了妻子出轨，最后被判刑的人却是你
- 老婆出轨，我赢了官司，却输掉了尊严
- 当真相也有不能越过的边界

#### 沉浸体验型标题规则

沉浸体验型标题首先回答“今天具体体验谁或什么处境”。优先选择最有性格、权力感、欲望、怪癖或处境反差的身份表达；一个短身份已经足够鲜明时，可以直接作为标题，不必追加结局或强行制造反转。

可灵活选择以下形式：

- 鲜明身份：`班级里官威十足的班干部`
- 具体处境：`35岁失业后拿全部积蓄加盟`
- 欲望或能力：`把所有徒步客都当成间谍的民宿老板`
- 关键选择与代价：`月薪3万去远洋捕鱼，半年后只想下船`
- 事实反转：仅在反转本身确实是本期最强卖点时使用。

不推荐 `老师最信任的那个人，最后没人愿意和他同桌`：它把身份藏起来，用模糊关系和“最后……”套式代替具体体验，观众第一眼不知道这期讲的是官威十足的班干部。

不要机械套用“你只是……”“最信任的那个人……最后……”或任何统一公式，也不要把冷开场原句直接当标题。品牌引导语仍单独朗读“今天你要体验的人生副本是”，正式标题字段只填写其后的具体主题，例如 `班级里官威十足的班干部`。

场景基本单元：

> 环境细节 → 人物动作 → 外界反馈 → 身体反应 → 内心解释 → 一个小选择

每个场景至少推动欲望、能力、身份、代价或认知中的一项。

## 3. 四种结构分支

### 欲望下坠型

适合成瘾、灰色消费、快速赚钱、危险职业和情绪依赖。

> 排斥 → 压力击穿防线 → 第一次体验 → 强烈奖励 → 学习规则 → 加大投入 → 形成依赖 → 代价显形 → 尝试退出 → 触发事件 → 复吸或无法退出 → 回到入口

重点不是人物不知道有害，而是有害事物确实解决了一个真实痛点。

### 自欺清算型

适合盲目自信、主角病、装腔、虚假成功学和错误归因。

> 偶然事件 → 错把运气当实力 → 搜集支持幻觉的证据 → 多场景表演特殊 → 外界冷漠或配合 → 幻觉膨胀 → 客观结果清算 → 承担后果或继续编造解释

让人物的逻辑局部说得通，整体逐渐显出荒谬。

### 极致爽感型

适合富二代、绝对权力、顶级天赋和极端身份体验。

> 幼年无意识特权 → 第一次看见别人因自己弯腰 → 意识到身份力量 → 权力尺度扩大 → 日常行为影响大量他人 → 站在规则之外 → 冷峻画面定格

不要强塞报应。爽点来自普通人奋斗一生的东西只是人物的生活背景；可用隔绝或冷漠增加余味。

### 逆袭代价型

适合天赋、颜值、网红、运动、艺术、草根创业和海外务工等题材。

> 底层处境 → 机会出现 → 第一次被市场验证 → 学习规则 → 真实成功 → 维持成功的成本上升 → 害怕失去或被替代 → 面对不可追回之物 → 回扣最初承诺

不要把成功写成骗局。人物确实改变命运，也确实把一部分自己抵押给了成功机制。

## 4. 通用八段母版

### 1. 身份落地与反差钩子（0%—8%）

在最短时间内交代人物是谁、缺什么、正在发生什么。前 100—150 字进入具体场景，包含时空锚点、处境物件、动作和反差。

### 2. 原始缺口与第一次诱因（8%—20%）

明确人物缺少的是贫穷、亲密、尊严、控制、关注还是证明自己的机会。让压力事件和诱因击中这个缺口，使第一次越界在当时看来合理。

### 3. 第一次奖励与危险等式（20%—32%）

用身体感受、外界反应或具体收益写清楚人物为什么继续。形成一句简单而诱人的等式：

> `[小代价]`可以换来`[巨大即时奖励]`。

或：

> 在这里坚持一个月，等于在原来的生活里坚持三个月。

### 4. 学习规则与三阶升级（32%—55%）

依次写：从不会到熟练、从熟练到精通、从精通到身份变化。通过工具、衣服、住所、账户、称呼和他人态度表现升级，不要只说“你越来越厉害”。

### 5. 巅峰体验与认知变形（55%—68%）

让人物得到最初想要的东西，并形成最致命的错误认知。回答人物获得了什么、开始忽视什么、误以为掌控了什么。

### 6. 代价具象化（68%—80%）

让代价至少落在身体、关系、金钱、心理或身份中的两个层面。先写膏药、未接视频、消费账单、空房间等证据，再允许旁白总结。

### 7. 清算、复吸或真相揭露（80%—94%）

用成绩、余额、体检单、客户电话、替代者、数据、死亡或无法挽回的关系完成清算。避免靠旁白训话强行制造结论。

根据分支选择：看清后仍返回、客观结果击碎幻想、不安排报应而推到规则之外，或同时承认成功与代价。

### 8. 首尾回扣与最后画面（94%—100%）

召回开头的地点、动作、数字或核心物件，让它从机会变成代价、循环或真相。把最后的情绪落在一个能直接生成画面的动作上；主题判断最多一句。

## 5. 场景与语言规则

### 先给证据，再给判断

- 不写“你越来越紧张”，先写手指、呼吸、手机或物件动作。
- 不写“你越来越有钱”，先写购物车、住所、称呼或账户的变化。

### 有节制地使用数字

使用时间、价格、余额、排名、次数和年龄制造可信度与清算感。数字必须推动剧情；不要用无法核实的精确数据装饰文稿。

### 让感官细节表现处境

每个场景选择一到两种主要感官。优先选择能体现阶层、生活和情绪的细节，不要为华丽而写满五感。

### 控制对话

只保留承担诱惑、身份确认、权力变化或清算作用的对话。删掉不能改变关系、信息或选择的寒暄。

### 让核心物件出现三次

1. 开头表现普通处境或机会。
2. 中段成为奖励、承诺或身份象征。
3. 结尾成为代价、循环或真相象征。

### 允许重复，但必须升级

可以连续使用“你开始”“你不再”“你以为”等节奏句，但后一句的信息强度必须高于前一句。避免整篇机械重复。

## 7. 成稿质检

交付前先统计正文的非空白中文字符数。默认任务只有落在 2400—2600 字内才进入下列质检；超过 2600 字时，依次删去重复判断、同义情绪、无升级作用的例子和过长过渡，不能删掉合理诱因、三阶升级、具体清算与结尾回扣。低于 2400 字时，只补能形成新画面并推动命运机制的内容。

每项 0—2 分。总分低于 24 分时先重写结构。即使总分达标，缺少合理诱因、升级、具体清算或结尾回扣中的任意两项，也要重写。

| 检查项 | 分数 |
|---|---:|
| 标题脱离正文仍能说清体验对象或事件，并有至少一个具体鲜明的点击钩子；没有为套公式牺牲自然与简洁 | /2 |
| 前 100—150 字进入具体场景 | /2 |
| 人物最深缺口清晰 | /2 |
| 第一次选择在当时合理 | /2 |
| 即时奖励强且具体 | /2 |
| 存在危险等式或错误认知 | /2 |
| 中段至少三次实质升级 | /2 |
| 升级通过动作、物件或关系体现 | /2 |

## 8. 禁止照搬的缺陷

- 不继承参考转写稿里的同音错字、人称错误、异常断句或标点缺失。
- 不反复套用“死一般寂静、血液冻结、空气粘稠、瞳孔收缩”等现成表达。
- 不为真实感滥用品牌、材质和精确到可疑的数字。
- 不让每一段都使用强烈比喻，保留强弱层次。
- 不在第一次奖励后马上说教，先让观众充分体验奖励机制。
- 不把人物写成纯粹的坏人或蠢人。
- 不在结尾连续解释寓意，让核心物件和最后动作承担主题。
- 不把未核实的医学、法律、录取或行业细节写成事实。
# 真实人物原型的表达边界

用户说素材来自身边真实人物时，默认做匿名化和虚构化处理，只批评可观察的行为、边界感、操控方式及其后果。不要把性别气质、外貌特征、学历或阶层当作人格缺陷，也不要加入可用于定位当事人的独特信息。可以写“反复越界接近异性、把冒犯包装成幽默、在社交平台刻意经营人设”，不要用“娘、麻子、大专所以低人一等”等标签承担讽刺功能。
